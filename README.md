# KeyNoise Guard (キーボード打鍵騒音 リアルタイム検知システム)

[クリックでアクセス](https://noise-detector-ruby.vercel.app/)

KeyNoise Guardは、キーボードの打鍵音（特にタイピング時の「強打」や騒音）をマイク入力からリアルタイムに検知・可視化し、快適なタイピング環境と周囲への配慮をサポートするWebアプリケーションです。

ブラウザとマイクだけで動作し、サーバーへの音声データ送信は一切行わないため、セキュリティやプライバシー面でも安全に利用できます。

マイクによってはノイズ抑制機能が強い場合があります。ノイズ抑制を軽減した状態でお使いください。

---

## 🌟 主な機能と特徴

### 1. リアルタイム音声解析と波形表示
- **Web Audio API**を使用した高速な音声解析。
- キャンバス上にリアルタイムで音声波形と検知レベル（シグナル比率）を描画。

### 2. 高精度な打鍵音検知ロジック（ノイズ除去）
- **ハイパスフィルタ (600Hz):** 人の声の基本周波数や空調などの低周波ノイズをカットし、打鍵音の鋭い高周波成分を強調します。
- **急上昇率ゲート (Rise-rate gate):** 音量が緩やかに上がる話し声と異なり、1フレームで急峻に立ち上がる打鍵音のトランジェント（過渡特性）を判定して誤検知を防ぎます。
- **持続信号拒否 (Sustained-signal rejection):** 一定以上の音量が持続する信号（話し声や空調音など）を検知対象から自動で除外します。

### 3. 多彩なキャリブレーションモード
- **静寂キャリブレーション:** 周囲の静かな時のノイズフロア（基準値）を測定し、個々の環境に合わせた最適なしきい値を設定します。
- **打鍵音パターン学習 (スペクトル指紋):** 実際にキーを数回入力し、その周波数特性を「指紋（フィンガープリント）」として学習。コサイン類似度を用いて、打鍵音に類似した音だけを検知します。
- **動的ノイズ追従モード:** 周囲の環境騒音の変動に合わせて、リアルタイムでノイズフロアを自動追従・調整します。

### 4. 便利なユーザーインターフェース
- **keydown 連携モード (キー連動ゲーティング):** Webページ上で物理的にキーが入力された直後（350ms間）だけ音声解析を有効にすることで、周囲の雑音による誤検知を極限まで減らします。
- **Picture-in-Picture (PiP) 表示:** 解析画面やレベルメーターを小さなフローティング窓（PiP）として画面隅に常時表示可能。作業中のゲームやテキストエディタの裏で動作させながら監視できます。
- **ダーク/ライト テーマ切替:** 使用環境に合わせて目に優しいデザインへ変更できます。
- **アラート機能:** 許容値を超えた強打を検知すると、画面が赤くフラッシュ・振動し、オプションで警告音を鳴らせます。
- **ログ記録とCSV出力:** 検知した時間や強度のログをリアルタイムでリスト化。CSVファイルとしてエクスポート可能です。

---

## 🚀 使い方

1. 本リポジトリをクローンまたはダウンロードします。
2. フォルダ内の `index.html` をブラウザ（Google Chrome や Edge 推奨）で開きます。
3. 画面上の「**監視開始**」ボタンをクリックし、マイクの使用許可を与えます。
4. 必要に応じて「キャリブレーション（静寂/打鍵音）」を行い、しきい値やゲインを調整してください。

*※ PiP表示機能は、Document Picture-in-Picture API に対応したブラウザ（最新の Chrome/Edge 等）でご利用いただけます。*
