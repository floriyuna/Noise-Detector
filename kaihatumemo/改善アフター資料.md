# KeyNoise Guard 改善アフター資料 (システム＆UI/UX改善報告書)

本プロジェクト「KeyNoise Guard」におけるマイク音声拾い漏れ、話し声やノイズによる誤検知、およびUI/UX改善と機能追加の要望に対し、今回実施したすべての対応結果をまとめました。

## 2. 刷新されたシステム構成と処理フロー

改善後のコンポーネント連携および音声処理のフローは以下の通りです。

```mermaid
flowchart TD
    Mic([物理マイク]) -->|生の音声信号| HPF[① ハイパスフィルタ 600Hz]
    HPF -->|低音/音声の基本周波数をカット| Gain[② 入力ゲイン増幅ノード]
    Gain -->|増幅された高周波信号| Analyser[③ アナライザー (FFTサイズ1024)]
    
    Analyser -->|時間領域: 瞬間RMS/ピーク| Detect{④ 打鍵検知・判定ロジック}
    
    subgraph 誤検知防止フィルター [新設：トリプルノイズ抑制ゲート]
        GateA{🔑 キー連動ゲート\n※ONの場合のみ} -->|keydownイベント後350msのみ通過| GateB
        GateB{🎚 急上昇率ゲート\nRise-rate} -->|1フレームでの急激な音量上昇か| GateC
        GateC{⏱ 持続信号拒否ゲート\nSustained-signal} -->|しきい値超えが5F未満か| Success[検知判定クリア]
    end
    
    Detect -->|シグナル強度比率| GateA
    Success -->|強打イベント発生| Alert[⑤ 警告・インターフェース部]
    
    subgraph 警告 & UI同調
        Alert -->|赤枠点滅 & 画面振動| UI_Main([メイン画面])
        Alert -->|同期フラッシュ & カウントアップ| UI_PiP([最前面 PiPウインドウ])
        Alert -->|オシレータによる電子音| Beep([スピーカー出力])
    end
```

## 3. 追加された機能の詳細と使い方

### 🔑 キー連動モード (Keyboard Gating Mode)
- **使い方**: 画面右の「警告・検知設定」にある「**キー連動モード**」をONにします。
- **仕組み**: ブラウザで別の作業中であっても、キーボードの何かしらのキーを押した瞬間にJSが `keydown` イベントを検知し、350msの間だけマイクからの打鍵音判定を行います。
- **効果**: 会話中やエアコンの風があたっても全く誤反応しなくなり、タイピング中の「エンターキー強打」のみを完全に狙い撃ちして検知できます。

### 🎚 ノイズゲート (急上昇率)
- **使い方**: 画面左の「ノイズゲート（急上昇率）」スライダーを調整します。
- **仕組み**: キーボードを叩く音は極めて短い時間で音が立ち上がりますが、話し声や環境ノイズは数ミリ秒かけて比較的緩やかに音が立ち上がります。この「立ち上がりの急峻さ（Rise-rate）」を数値化して足切りします。
- **調整**: スライダーを上げるほど「急激に発生した音」だけを検知し、会話での誤検知をカットできます。

### 📺 Document Picture-in-Picture (PiP)
- **使い方**: ヘッダーの「📺 PiP表示」ボタンをクリックします。
- **仕組み**: Chromium系ブラウザの最新機能で、HTMLとCSSを流し込んだ「常に手前に表示されるサブウィンドウ」をポップアップします。
- **機能**: メイン画面と連動してダークモードや検知回数、リアルタイムの波形や赤色のフラッシュが完全に同調して表示されます。

### 🌓 テーマ切替 (ダークモード)
- **使い方**: ヘッダーの「🌓 テーマ切替」ボタンをクリックします。
- **仕組み**: 画面全体のカラーテーマをライトとダークで切り替えます。選択したテーマはブラウザに記憶され、次回起動時も適用されます。

## 4. チューニングのアドバイス

もし動作感度を調整したい場合は、以下の順序で設定を行ってください。

1. **ベースノイズの測定**:
   監視開始後、静かな状態で「①静寂測定（3秒）」を実行してください。環境に適したしきい値が自動で設定されます。
2. **マイク感度の調整**:
   キーボードを叩いた時に「シグナル比率」がしきい値（デフォルト2.00程度）を大きく超えない場合は、「マイク入力ゲイン」を上げて音量を増幅してください。
3. **誤検知のカット**:
   エアコンや他のノイズで反応する場合は「キー連動モード」を有効にするか、「ノイズゲート (急上昇率)」を 0.8 〜 1.2 程度に上げてください。
